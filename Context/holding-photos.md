# Holding demo photos

Drop **square photos** in this folder to replace the illustrated placeholder tiles on the wall and
the spin reel. They're only used while there's little/no real data — as colleagues post real meetup
photos, these get pushed out automatically.

## Exact filenames to use (one per seed pair)

The app looks for these exact names (lowercase, `.jpg`). Save each photo as the pair it represents:

| Pair (dummy name) | Scene | Filename |
|---|---|---|
| Anna & Mateo | a walk & talk | `anna-and-mateo.jpg` |
| Priya & Tom | lunch together | `priya-and-tom.jpg` |
| Lena & Sven | a digital / Teams coffee | `lena-and-sven.jpg` |
| Ravi & Chloe | a coffee on site | `ravi-and-chloe.jpg` |
| Marco & Ines | a litter-pick walk | `marco-and-ines.jpg` |
| Yuki & Ben | a coffee | `yuki-and-ben.jpg` |

## Tips
- **Square** (1:1) works best — they're shown in square frames. Roughly 600×600px is plenty.
- Use **royalty-free / stock or AI-generated** images of two colleagues doing the activity (walk,
  lunch, video coffee, coffee, litter-pick) — nothing identifiable/real, since these are placeholders.
- Keep file sizes small (a few hundred KB) so the page stays fast.
- If a file is missing, the app automatically shows the illustrated scene tile instead — so it never
  looks broken.
- Want more/other pairs? Add the photo here and tell me the name + scene and I'll add it to the seed list.

_Filenames are derived from the pair name: lowercase, "&" → "-and-", spaces → "-". e.g. "Anna & Mateo" → `anna-and-mateo.jpg`._
