# Dev session logs — ZB MeetUP

One file per working session — `YYYY-MM-DD_short-title.md` — logging **what we did**, key decisions,
and **any open items** to pick up next time. The living, grounded project overview lives in
**`../context/CONTEXT.md`** (read that first).

Convention (same as ZB Cup): at the end of a session, write the record here and update `CONTEXT.md`'s
state + "Last updated" line. At the start, skim the last 1–2 records + `CONTEXT.md`.
