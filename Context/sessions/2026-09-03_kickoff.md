## Key decisions captured
- Concept: daily colleague-matching engagement app; human-connection-first; live before the **Oct 4**
  engagement survey.
- Matching hard rule: **floor workers (Warehouse Clerk / NonEE Warehouse Clerk, 155 people, all
  On-Site) match only with on-site colleagues; everyone else can match with anyone.**
- Loop: spin → request → accept → shared space → photo (5 pts) + 3 questions (5 pts) → history.
- 2 respins/day; never the same person twice; questions tiered (high-value first); answers **private**,
  photos **public** on a community wall; Excel export for the idea-bank harvest; GDPR consent at sign-up.
- Same stack as ZB Cup (HTML/CSS/vanilla JS, GitHub Pages, Firebase, no build) + the `zimmer-app-design` system.
